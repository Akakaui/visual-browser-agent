# Playwright research notes

Sources consulted:

1. https://playwright.dev/ — Playwright supports web automation for testing, scripting, and AI agents; one API for Chromium, Firefox, and WebKit; Playwright Test includes auto-waiting, assertions, tracing, and parallelism; resilient locators include role, label, placeholder, and test id.

2. https://playwright.dev/mcp/introduction — Official Playwright MCP uses structured accessibility snapshots and describes 40+ tools across navigation, forms, network mocking, storage, tracing, video, PDF, dialogs, tabs, and optional mouse/vision primitives. It also documents persistent sessions, coding-agent use, and the distinction between MCP and CLI.

3. https://playwright.dev/docs/browsers — Playwright supports Chromium, Firefox, WebKit, branded Chrome/Edge channels, device parameters, headed/headless operation, and browser installation through the Playwright CLI.

4. https://playwright.dev/docs/api/class-browsercontext — BrowserContext provides independent browser sessions and APIs for cookies, initialization scripts, permissions, storage, pages, routing, and context lifecycle.

These sources support the comparison claim that Playwright is the low-level browser automation/test platform, while Visual Browser Agent is an agent-facing orchestration, safety, evidence, profile, and integration layer built on Playwright.
